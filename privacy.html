Privacy policy

Personal Organizer is an integration being developed for its owner's personal use with Linear, Habitica, Google Calendar, and Codex.

Last updated: November 8, 2026

Information accessed and why

When configured and authorized, the integration accesses information needed to carry out the owner's requests: Linear projects and issues, Habitica routines and completion records, and Google Calendar events. Calendar data can include event titles, descriptions, dates and times, locations, reminders, recurrence information, and attendees.

Google Calendar access is used to retrieve upcoming commitments and to create, modify, or delete events requested by the owner. The integration requests event access rather than access to unrelated Google services.

Storage and processing

The integration is designed to run locally using API credentials and Google OAuth tokens stored on the owner's device, outside the public website repository. The connected services retain their own records. Local tool output and Codex conversation history may also contain information retrieved during a request.

When Codex is used to process a request, relevant prompts, tool results, and service data may be sent to OpenAI for processing under the owner's account settings and OpenAI's applicable terms and privacy policy. The owner should review those settings before accessing sensitive information.

Sharing and use

The integration is not designed to sell personal information, serve advertising, or share calendar data with unrelated third parties. Data is exchanged with the connected services and with OpenAI as needed for the requested workflow. Actions such as inviting attendees or creating shared events may make information visible to others through the connected service.

This website

These information pages contain no analytics scripts, advertising, forms, or application cookies. They do not receive API credentials or calendar data. GitHub Pages hosts the website and may process technical request information, including IP addresses, under the GitHub privacy statement.

Control, revocation, and deletion

The owner can stop using the integration and revoke Google access at any time through Google Account connections. Linear and Habitica credentials can be revoked or regenerated through those services.

Deleting local credentials and tokens removes the local authorization material. Local logs and Codex conversation history must be managed separately. Revoking access does not delete existing events or records in the connected services; those can be managed directly in each service.

Contact and changes

For questions, contact the maintainer through the project issue tracker. Issues are public; do not include credentials or private calendar information. This policy will be updated as the integration's behavior changes.
